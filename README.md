# Виртуальная лаборатория «Биометрия» - MVP

Первая итерация: модуль **«Распознавание отпечатков пальцев»** + общий каркас, на который
позже добавляются лицо, радужка, сетчатка и интеграции (AI edu, LMS).

## Запуск в PyCharm

1. Откройте папку `biometric-lab` как проект (`File → Open`).
2. Создайте интерпретатор: Python 3.11 или 3.12, Virtualenv в `.venv`.
3. В терминале PyCharm:
   ```
   pip install -r requirements.txt
   uvicorn app.main:app --reload
   ```
4. Откройте http://127.0.0.1:8000 (документация API: http://127.0.0.1:8000/docs).

Запуск из PyCharm кнопкой: `Run → Edit Configurations → + → Python`, модуль `uvicorn`,
параметры `app.main:app --reload`.

Тесты: `pytest`.

## Что умеет MVP

- 8 этапов обработки с картинкой и пояснением: grayscale → сегментация → нормализация (CLAHE) →
  поле ориентаций → Gabor → бинаризация → скелетизация → minutiae (● окончание, ▲ разветвление).
- Таблица minutiae (X, Y, угол, тип, качество).
- Сравнение двух образцов: поиск совмещения (голосование Хафа по повороту и сдвигу),
  similarity, визуализация совпавших точек.
- Ползунок threshold: решение MATCH / NO MATCH пересчитывается сразу.
- Метрики на наборе пар «свои / чужие»: FAR, FRR, EER, Accuracy, график от порога.
- Параметры эксперимента в интерфейсе, включая добавочный шум.
- ИИ-наставник: режимы Hint / Explain / Diagnose (по умолчанию на правилах, без ключа).
- Журнал экспериментов в SQLite, экспорт в CSV.
- Загрузка своего изображения отпечатка (в образец B).
- **3D-визуализация**: рельеф гребней как поверхность (Three.js), вращение мышью, масштаб колесом,
  маркеры minutiae (● окончания, ▲ разветвления), выбор текстуры (исходное, Gabor, бинаризация, скелет),
  регуляторы высоты гребней и кривизны пальца, режим сетки. API: `POST /api/v1/biometrics/fingerprint/relief`.

## Модуль «Распознавание лица»

Этапы: исходное фото → детекция (рамка, confidence) → ключевые точки → выравнивание →
нормализация освещения → face embedding → cosine similarity → threshold → MATCH / NO MATCH.

- **Два режима для сравнения классики и нейросети**: Haar-каскад + LBP-гистограммы (работает сразу, без скачивания)
  и YuNet + SFace (нейросети OpenCV Zoo, модели скачиваются в `models/`).
- Модели: `python -m scripts.download_models` (или автоматически при старте, если есть интернет).
- Галерея: `datasets/faces/<имя>/<фото>.jpg`. Быстрый способ взять открытый LFW: `python -m scripts.prepare_lfw`.
- Метрики FAR / FRR / EER считаются на парах «один человек / разные люди» из галереи (нужно 2+ человека, 2+ фото у каждого).
- Для LBP используется вычитание «среднего лица» галереи (нужно 3+ человека), иначе сходство у всех лиц завышено.

## Практикум: код (вкладка «Практикум: код»)

Студент пишет Python-код в браузере (редактор Monaco, при отсутствии интернета простое поле), запускает его на примере и отправляет
на автопроверку. 5 заданий: бинаризация, нормализация, crossing number (минуции), косинусное сходство + порог, FAR/FRR.
- **Проверка:** код выполняется в отдельном процессе, результат сравнивается с эталоном на базовых и граничных тестах.
- **Оценка по рубрике (10 баллов):** запуск без ошибок 2, базовые тесты 4, граничные случаи 3, контрольный вопрос 1. Веса меняются в JSON задания.
- **ИИ-поддержка:** разбор ошибок (синтаксис, типы, индексы, пустой return, таймаут) и 4 уровня подсказок. Полное решение открывается
  только после 3 попыток проверки (проверяется на сервере). Попытки и подсказки пишутся в SQLite.
- **Новое задание:** файл `app/tasks/NN_имя.json` (текст, шаблон, подсказки, рубрика, вопрос) + эталон и тесты в `app/sandbox/reference.py`.
- **Безопасность (честно):** защита учебная, а не промышленная. Блокируются импорты кроме numpy/cv2/skimage/math и др., `open`, `eval`,
  служебные атрибуты, чтение и запись файлов через numpy/cv2. Процесс ограничен по времени, на Linux/macOS ещё по памяти и CPU;
  на Windows ограничение только по времени. Для боевого сервера запускайте выполнение в Docker (без сети, с лимитами памяти).

## Обучение нейросети распознаванию (вкладка «Обучение распознаванию»)

Маленькая свёрточная сеть (3 conv-слоя → embedding → классификатор) написана на NumPy, PyTorch не нужен.
Она учится на отпечатках (синтетика) или на лицах из `datasets/faces` (нужно 2+ человека, 2+ фото с найденным лицом).
Сервер обучает её в фоне и сохраняет «снимок» каждой эпохи: loss и точность, EER, фильтры, карты признаков трёх слоёв,
проекцию embeddings, распределения «свои / чужие», ответы на тестовых образцах, изменение весов каждого слоя.
Схема сети показывает слои, карты признаков каждого фильтра, силу связей и то, какие веса изменились с начала обучения. Ползунком можно вернуться к любой эпохе. API: `/api/v1/training/{start,stop,status,snapshot/<эпоха>}`.
Обучение с нуля маленькой сети на малом числе фото - учебная демонстрация, это не замена готовой модели SFace.

## Площадка нейросети

Отдельная вкладка по образцу TensorFlow Playground: слои, нейроны, признаки, learning rate, активация, регуляризация,
наборы данных (в том числе «Биометрия: свой / чужой»). Считается в браузере, сервер не нужен.

## Данные

`datasets/synthetic/` - 12 синтетических пальцев × 3 оттиска (созданы генератором, реальных людей нет).
Оттиски одного пальца отличаются поворотом, сдвигом, шумом и размытием.
Пересоздать: `python -m scripts.generate_dataset`.
Свои наборы (SFinGe, FVC и др.) можно подключить, заменив `_gray()` в `fingerprint/module.py`.

## Структура

```

  api/v1/                    REST: biometrics, tutor, experiments
  core/                      config, db, imaging
  modules/
    base.py                  контракт BiometricModule
    registry.py              регистрация модулей

  services/                  tutor, experiments, events
  web/index.html             интерфейс
datasets/  scripts/  tests/
```

## Как добавить новую биометрию (лицо, радужка...)

1. Создайте `app/modules/face/module.py` с классом, наследующим `BiometricModule`
   (`list_samples`, `process`, `compare`, при желании `evaluate`).
2. Добавьте `register(FaceModule())` в `app/modules/registry.py`.
3. Эндпоинты `/api/v1/biometrics/face/...` заработают сразу (маршруты общие).
4. В `index.html` включите вкладку.

## Путь к интеграциям

- Версионируемый REST API (`/api/v1/...`) подходит для Next.js/NestJS-фронта из ТЗ и для AI edu.
- Каждое действие студента пишется в таблицу `events` (основа для Learning Analytics).
- Журнал экспериментов и права доступа вынесены в сервисы: можно заменить SQLite на PostgreSQL.
- Позже: авторизация и роли, автооценивание по JSON-правилам заданий, RAG для наставника, Docker для запуска кода студентов.

## ИИ-наставник

`.env` (по образцу `.env.example`): `TUTOR_PROVIDER=rule` (по умолчанию) или `openai` + `OPENAI_API_KEY`.
Для `openai` нужно `pip install openai`. При ошибке API наставник автоматически возвращается к правилам.
Новый провайдер (Gemini, Ollama) - ещё один класс `TutorProvider` в `app/services/tutor.py`.

## Ограничения MVP (честно)

- Метод сравнения учебный: ориентации minutiae определены с точностью до 180°, допустимый поворот до ±40°.
  Это не промышленный матчер.
- Метрики считаются на синтетике, поэтому разделение «своих/чужих» получается почти идеальным (EER ≈ 0).
  На реальных данных (FVC и т.п.) числа будут хуже, это нормально.
- Plotly и Three.js подгружаются через CDN: для показа нужен интернет (или скачайте файлы в `app/web`).
- 3D построен по карте высот из изображения (псевдо-3D рельеф), это не реконструкция реального пальца.
- Первый расчёт метрик занимает около 8-10 секунд, дальше берётся из кэша.
- Модуль лица: Haar даёт грубые ключевые точки (глаза ищутся каскадом, нос и рот по пропорциям), YuNet точнее. Качество SFace и LBP на ваших данных я не измерял: модели в моей среде недоступны.
- Обучение CNN идёт на CPU без GPU: 30 эпох на 12 пальцах занимают около 30-90 секунд в зависимости от компьютера.
- Выполнение кода студента в редакторе (Monaco + Docker-песочница) пока не реализовано.
