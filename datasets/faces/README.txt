Галерея лиц для лаборатории.

Структура:  datasets/faces/<имя_человека>/<фото>.jpg
Для оценки метрик (FAR/FRR/EER): минимум 2 человека, по 2-3 фото у каждого (лучше 8-10 человек).

Подходит открытый набор LFW (Labeled Faces in the Wild): скопируйте несколько папок людей, у которых есть 2+ фото.
Используйте только открытые исследовательские наборы или фото тех, кто дал согласие.
Не собирайте биометрию студентов без необходимости.
